# Worked expansions of naive prompts

Each row is a real prompt shape, what it must become, and the failure it avoids.

---

### "Add X to the zoo" / "bring in the fauna"

**Expand to:** what is X's *operator*? What does it consume and return? Which
existing type does it reuse? What matched control would reproduce its effect
without it? Preregister that control before implementing X.

**Avoids:** the m1-bordon failure — a fixed seek-heavy policy reproduced the
entire benefit with holonomy, hyperbolic transport, regluing and holoport all
disabled. Adding an organ is not evidence the organ does anything.

---

### "Test whether <geometry> helps"

**Expand to:** helps *at what*, measured how, against which dimension-matched
control, on which held-out family, at what compute parity? Then: does the answer
survive a moving-frame audit?

**Avoids:** S3 — the hypercomplex clause was killed by a *tie*, not a loss.
Quaternionic coordinates were exactly identical to a matched real sheaf on their
home ground. "May improve" is not supported by a tie.

---

### "Implement <evocative architecture>"

**Expand to:** name the carrier, the operator, the invariants, the kill condition.
If any of the four is missing, the object is **S** and stays S until it has all
four. Say which is missing rather than inventing it.

**Avoids:** S4-G100 — a fully typed chamber with manifest, validator, 65 tests and
ten preregistered gates still failed six of them, because the mechanism was a
budget-to-search-space artifact. Ornamentation is not evidence.

---

### "Prove <claim about the algebra>"

**Expand to:** state it as an exact identity, check it numerically across the
Cayley–Dickson ladder, **and check whether something trivial reproduces it**.

**Avoids:** the conjugate anti-pair — the identity `A(ā,b,c) = −A(a,b,c)` is true
to 5e−16, but plain negation gives the same cosine −1 at *exactly* 0.0 error, so
conjugation carries no information. Always run the trivial-mechanism control.

---

### "Repeat the testing in a moving frame"

**Expand to:** build the frame group properly (vertex relabelling × edge
reordering × gauge), verify **equivariance first**, then loop closure, then orbit
spread. Classify each measurement orbit-collapsed or orbit-resolving.

**Avoids:** the S5 near-miss — the first frame action re-sorted edges, which is a
canonicalisation rather than a group operation, so `equivariance_defect` returned
infinity. The table had already been computed and looked publishable. The gate
invalidated it before it was reported.

---

### "Make it more quantum" / "natively quantum X"

**Expand to:** where does authority actually live? If a classical loop measures,
decides and updates parameters, the system is *classical controller + quantum
plant*. Required controls: matched classical stochastic, dephased, separable,
frozen-morphology, and oracle-cost accounting.

**Avoids:** claiming quantum advantage from a redescribed variational circuit.
The one real separation in this repo — `b` classical queries vs 1 quantum — is
bounded three ways, including that building the coherent oracle costs `E`
classical reads, i.e. *negative* advantage outside the oracle model.

---

### "Why did that fail? / rescue it"

**Expand to:** report the failure, register the retirement with its corrections,
and identify the *narrower true statement* that survives. Keep the module and the
experiment so the negative result stays reproducible.

**Avoids:** the standing rule — do not rescue a failed invariant by adding a
richer ontology. A negative result is a valid completion.
